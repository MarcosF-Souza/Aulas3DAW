# Aulas3DAW

Bem-vindo ao meu repositório da disciplina **Desenvolvimento de Aplicações Web (3DAW)** do curso superior de **Análise e Desenvolvimento de Sistemas** da **FAETERJ-RIO**! Aqui você encontrará conteúdos essenciais para entender os princípios de desenvolvimento web, desde configuração de servidores até front-end e back-end.

## 📌 Conteúdo da Disciplina

A disciplina aborda os seguintes tópicos:

1. **Criação e Configuração de Servidores WEB**  
   - Configuração de servidores (Apache, Nginx)
   - Ambientes de hospedagem
   - Virtual hosts e domínios

2. **Administração e Configuração de Dashboard Web**  
   - Painéis de controle administrativo
   - Gerenciamento de conteúdo
   - Segurança e permissões

3. **Aplicação e Configuração de CMS**  
   - WordPress, Joomla, Drupal
   - Instalação, customização e plugins
   - Temas e templates

4. **Desenvolvimento Front-end**  
   - **HTML5** – Estrutura semântica
   - **CSS3** – Estilização, Flexbox, Grid
   - **JavaScript** – Interatividade, DOM, eventos
   - **PHP** – Integração com back-end

5. **Interação Humano-Computador para Front-end**  
   - Princípios de usabilidade
   - Design responsivo
   - Acessibilidade na web

6. **Frameworks Front-end e Conexão com Back-end**  
   - Bootstrap, Foundation, Materialize
   - Consumo de APIs REST
   - Integração com back-end (PHP, Node.js)

## 🔧 Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript, Bootstrap
- **Back-end:** PHP
- **Servidor:** Apache / Nginx
- **CMS:** WordPress
- **Ferramentas:** VS Code, Git, GitHub

## 🚀 Como Executar os Exemplos
1. Clone este repositório:
 
  git clone https://github.com/MarcosF-Souza/Aulas3DAW.git
   
  Configure um servidor local (XAMPP, WAMP, ou LAMP) e aponte para a pasta do projeto.

  Importe o banco de dados se necessário.

  Acesse via navegador: http://localhost/Aulas3DAW
